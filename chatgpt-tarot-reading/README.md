# ChatGPT tarot reading: we asked its model for a card 10,000 times. It pulled The Star 10,000 times

Full write-up: https://startarot.online/research/chatgpt-tarot-reading?utm_source=github&utm_medium=data-repo&utm_campaign=research-2026-11-14

What OpenAI chat models "pull" when asked for a tarot card, counted through the API: 44,696 answers from 22 dated models (May 2024 to October 2026) and the alias `chat-latest`, the model behind ChatGPT's Instant replies. `chat-latest` named The Star in 10,000 of 10,000 draws, gave no reversed and no Minor Arcana card, and kept The Star in 15 of 16 languages; the card follows the question asked and the zodiac sign given, and the effective deck narrows from 9.2 cards on GPT-4o to about one card on every model since April 2026. The hypotheses were written into the script before the full count; the page prints the outcome of each, the misses included.

This is the API, not the ChatGPT app: the app adds its own system prompt, the date, memory and tools.

## Files

- `ai-tarot-draws.csv`: the dataset behind every number on the page, one row per answer in each cell.
- `ai_tarot_draws.py`: the script that fetches the answers and computes everything; its docstring gives the design,
  the exact wording of every prompt, the hypotheses as written before the count and what was changed after it.

### Columns

| Column | Meaning |
|---|---|
| `condition` | Cell type: `neutral`, `fair`, `number`, `single`, `free`, `reversal`, `topic`, `spread`, `zodiac`, `language`, `date` |
| `variant` | Wording, topic, sign or language within the cell (exact text in the script's `NEUTRAL`, `FAIR`, `TOPICS`, `LANGUAGES` and the other prompt constants) |
| `model` | API model id; `chat-latest` is the alias |
| `position` | Card in a three-card spread: 1 past, 2 present, 3 future; empty elsewhere |
| `answer` | Card id (e.g. `the-star`, `ace-of-pentacles`) or, in `number`, the number; in `reversal` an extra row `(reversed)` counts answers marked reversed |
| `count` | Answers in this cell equal to `answer` |
| `cell_answers` | All answers in the cell |
| `cell_unparsed` | Answers in the cell that could not be mapped to a card |

## Reproduce

```bash
# Python 3.10+, standard library only
python3 ai_tarot_draws.py design            # cells and draw counts, no requests
OPENAI_API_KEY=... python3 ai_tarot_draws.py fetch
python3 ai_tarot_draws.py compute
python3 ai_tarot_draws.py validate
python3 ai_tarot_draws.py export
```

`fetch` makes new paid requests and stops at a budget cap (`AI_TAROT_BUDGET`, US dollars, estimated from the
usage the API returns; `AI_TAROT_RUN_OUTPUT_TOKENS` caps output tokens per run). Our fetch ran on 14 November 2026,
08:40–09:34 UTC; its estimated cost was about US$9. A new fetch measures the models as they are on its own day:
`chat-latest` in particular moves to newer models over time. Raw answers land in `ai-tarot-draws-data/` next to the
script; a copy run outside the StarTarot repository writes its CSV and JSON next to itself.
